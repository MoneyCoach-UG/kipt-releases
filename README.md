# KiPT Downloads

Offizielle Installationsdateien der KiPT-Produktfamilie von Imperium Apps GmbH.

## KiPT Voice

Windows-Versionen stehen unter [Releases](https://github.com/MoneyCoach-UG/kipt-releases/releases).
Release-Tags verwenden `voice-vX.Y.Z`. Jede Windows-Version enthält
`KiPTVoice-Setup-x64.exe` und `SHA256SUMS.txt` zur Integritätsprüfung.

Der produktbezogene Download-Kanal liegt in `channels/voice/windows.json`.
Er wird erst nach Veröffentlichung einer vollständigen Version aktualisiert.
Entwürfe und Vorabversionen werden nicht angeboten. Andere KiPT-Produkte
verwenden eigene Tags und Kanäle.

Dieses Repository enthält Installationsdateien und Veröffentlichungstools.
Der Anwendungscode wird separat verwaltet. Die Bereitstellung zum Download
räumt keine zusätzlichen Nutzungs- oder Weiterverbreitungsrechte ein.
